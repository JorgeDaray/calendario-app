=== CONTEXTO DEL PROYECTO: CALENDARIO DE DISPONIBILIDAD (ACTUALIZADO v8) ===
Stack: HTML puro, JavaScript (FullCalendar 6), CSS (Responsive), Supabase (PostgreSQL).
Host: Vercel.

-- ESTADO DE LA BASE DE DATOS (Supabase) --
Tablas Activas (Con REALTIME habilitado):
1. perfiles: id (UUID), nombre (TEXT)
2. disponibilidad: id, fecha, usuario_id, estado 
3. eventos: id, titulo, descripcion, ubicacion (TEXT), fecha_hora (TIMESTAMP), creado_por
4. asistencia_eventos: evento_id, usuario_id, estado (asistire|no_asistire|en_espera)

-- ESTADO DE LOS ARCHIVOS --
1. index.html: 
   - Login container, App container.
   - #modalCrearEvento y #modalRSVP (estilo Google Calendar).
2. style.css: 
   - Diseño responsivo, modales Flexbox, panel top 3 y tarjetas de asistentes.
3. app.js: 
   - Autenticación con supabase.auth.
   - Renderizado híbrido de FullCalendar (lee disponibilidad + eventos).
   - Generación de links (action=TEMPLATE) para Google Calendar.
   - [NUEVO] iniciarSincronizacionEnVivo() agregado usando clienteSupabase.channel(). Se suscribe a 'postgres_changes' en 'disponibilidad' y 'eventos' para disparar calendar.refetchEvents() y actualizarPanelMejoresDias() automáticamente sin recargar la página.
